# Xeravend

Welcome to Xeravend. This an open source 32/64 bit operating system project.

Why This Project?
================================
The goal of this project is we are not reinventing the wheel, just making it beter, faster, cleaner and less bloated than it has to be. 

We have only two main stream operating systems in the world: Windows or Linux / MAC OS. Windows is pushing for heavy cloud uasage, bloating, crashes, more restrictive which is turn away users. Linux has the too many distro problem and still feels technical.
